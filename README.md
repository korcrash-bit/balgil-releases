# 발길 · Android 설치 파일

대한민국 지도를 탐험하며 이동한 길 주변 100m를 밝히는 Android 앱입니다. Android 8.0 이상에서 사용할 수 있습니다.

이 저장소는 **APK 설치 파일과 배포 안내만 공개**합니다. 앱 소스는 별도 비공개 저장소에서 관리합니다. 실제 이동 기록, 개인 Google Drive 백업, 계정 토큰, 서명 키는 이 저장소에 포함하지 않습니다. GitHub가 자동으로 제공하는 `Source code` 압축 파일에는 이 배포 저장소의 안내 문서만 들어 있습니다.

## 설치와 업데이트

1. [최신 릴리스](https://github.com/korcrash-bit/balgil-releases/releases/latest)에서 `balgil-X.Y.Z.apk`를 다운로드합니다.
2. 기존 발길 앱을 **삭제하지 않고** APK를 설치합니다. Android 설치 확인 화면에서 업데이트를 진행합니다.
3. 0.2.1부터 **설정 → 업데이트 확인**에서 로그인 없이 새 버전을 확인하고 다운로드할 수 있습니다.

**0.2.0 사용자:** 설정 → 릴리스 주소 설정에 아래 주소를 한 번 저장한 뒤 업데이트를 확인하세요.

```text
https://github.com/korcrash-bit/balgil-releases
```

0.1.0 사용자는 최신 APK를 직접 설치하면 됩니다. 기존 앱과 동일한 서명키로 배포하며, 앱 내부 설치 전 패키지·서명·상위 버전을 검사합니다. 설치 여부는 Android 화면에서 직접 결정합니다.

## 위젯과 자동 기록 (0.3.0부터)

1. 업데이트 후 발길의 **설정 → 자동 기록 켜기 · 권한 설정**에서 안내에 동의합니다.
2. **정확한 위치**와 **항상 허용**을 설정합니다. Android 11 이상에서는 휴대폰의 앱 권한 설정에서 변경한 뒤 발길로 돌아옵니다.
3. **설정 → 홈 화면에 위젯 추가**를 누릅니다. 지원하지 않는 런처에서는 홈 화면을 길게 눌러 **위젯 → 발길**을 선택합니다.

한 번 켜 두면 앱을 매번 열지 않아도 기존 절전 방식으로 기록하며, 재부팅·업데이트 후에도 Android가 허용하면 재개를 시도합니다. 위젯에서 상태와 마지막 확인 시각을 보고 지도를 열거나 기록을 끌 수 있습니다. 위젯의 시각은 실시간 생존 신호가 아닙니다.

자동 기록은 기본으로 꺼져 있으며 위젯 추가만으로 켜지지 않습니다. 앱·위젯·알림의 종료 버튼은 자동 기록도 끕니다. 강제 종료·배터리 제한·제조사 절전 정책으로 중단되면 앱을 다시 열고 상태를 확인해야 합니다. 실제 기기에서 위젯·자동 재개·배터리 사용을 검증하기 전의 개발 빌드입니다.

## 기록과 백업

- 위치 기록은 휴대폰에 저장합니다. 직접 지정한 개인 Google Drive 파일에 백업할 수 있습니다.
- 지도 타일을 불러올 때 OpenStreetMap에 조회 지역과 접속 정보가 전달될 수 있습니다.
- 공개 APK 배포는 개인 위치 기록을 공개하는 기능이 아닙니다.

## 검증 범위

개인 체험용 개발 빌드입니다. 정책 검사와 APK 빌드·서명 검증을 수행하며 결과는 각 릴리스에 기록합니다. 실제 휴대폰에서의 설치, 화면 꺼짐 기록, Google Drive 동기화 및 배터리 절감률은 별도 기기 검증이 필요합니다. 깊은 절전에서는 GPS 재개가 지연될 수 있습니다.
